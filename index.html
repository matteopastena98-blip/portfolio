What the pipeline does

The agency wanted prospects that already spend on ads, in its own region, with a real company behind them. By hand that list took days and was full of guesses.

Input

Advertisers live in the Meta Ad Library for 18 keywords the client sells to.

Automated

One Python pass written with Claude Code: destination domain, site snapshot, VAT number, EU VIES check, region proof, named contact and published phone, score.

Result

48 deliverable leads, a 12.7% yield. The first run, about 27 machine minutes, became the basis of the client's quote.

What it changed

78 companies published a phone, 1 a findable personal email. The data moved the campaign to the phone.

How it handles errors

My automations are built to fail loudly and never fill a gap with a guess.

Show a failure in the demo

  • Gates re-read the data. Ten validators re-read every delivered value inside the source page saved during the run and recompute every number from the raw files.
  • Drop, don't guess. A row that fails a gate leaves the list. A missing VAT number stays missing.
  • Everything is logged. HTTP status per request, the VIES answer per company, the reason for every drop.
  • Rate limits are expected. In a 10,000-profile run for a fitness coach: backoff and retry, resumable output written one row at a time, and a circuit breaker that stops after 15 blocks with no data.
  • A person signs off. A reviewer agent and I check the list before it reaches the client. When the coach said some profiles were off target, I added vetoes and a sample check before the next batch.
